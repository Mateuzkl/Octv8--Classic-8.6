## Client layouts

Layouts override files from the repository root without replacing game logic.

- `classic`: uses the OTCv8 Classic 8.60 files from the repository.
- `retro`: uses the complete Retro layout shipped by the original Kondrah OTCv8.
- `mobile`: keeps the existing mobile-specific style overrides.

The selected layout is stored in `config.otml` and applied on the next client start.
